# python-basics-25BCON1581

## Session 4 Python Programs

### WHAT

This repository contains six fundamental Python programs:

- `armstrong.py`: Checks if a given number is an Armstrong number.
- `factorial.py`: Calculates the factorial of a number.
- `fibonacci.py`: Generates the Fibonacci sequence.
- `prime.py`: Checks if a number is prime.
- `pronic.py`: Checks if a number is a pronic number.
- `struct.py`: Stores and displays student data using a dictionary.

### RUN

You can execute each script directly from your terminal using Python:

- `python armstrong.py`
- `python factorial.py`
- `python fibonacci.py`
- `python prime.py`
- `python pronic.py`
- `python struct.py`

### NEEDS

- Requires Python 3.x installed on your system.
- No external dependencies or installations are required.
- The programs use Python's standard library.
